    これは何？

    プラネタリウムやドームシアターで3Dモデルを映し出すための3Dモデルビュアーです。 子ウィンドウのドームビューでドームマスター形式の映像を全画面表示し、プラネタリウムの外部映像入力として取り込めば、ドーム全体に映像を映し出すことができます。

    複雑な設定を必要とせず、限られた人しかアクセスできない環境も介さず、ブラウザだけで誰もが簡単に動作させられることを目指して作成しました。 ブラウザ環境に依存する制約はありますが、モデルの編集やアニメーションなど、3Dモデルを使った演出に必要な機能を豊富に含んでいます。 より高度な機能や安定した動作が必要な場合は、プラネタリウムに組み込まれているデジタルシステムやAmateras Model Viewerの利用をご検討ください。

    使い方

    より詳しい使い方を Notion記事 にまとめました。

    ブラウザで高速にレンダリングさせるため、ブラウザのGPUアクセラレータを有効にしておくことをお勧めします。処理能力の低い端末で利用した際や、解像度を上げた場合、サイズの大きなファイルを読み込んだ場合など、動作しずらくなることがあります。

    モデルの追加

    • 「モデルを追加」→「3Dモデル・画像」からSTL/OBJ/SVG/GLB/glTF形式のモデル、JPEG/PNG画像、または3D Gaussian Splatting形式の .splat / .ply を選択して読み込みます。 複数のオブジェクトを含むOBJファイルにも対応しますが、OBJファイルが参照する外部MTLファイルやテクスチャファイルは読み込みません。 GLB/glTFは外部ファイル参照を含まない形式に対応し、Draco・Meshopt・BasisUの圧縮拡張には対応しません。 3DGSのPLYはGraphDECO形式に対応し、.ksplat/.spzなどの圧縮形式には対応しません。ファイル選択はひとつずつですが、後で追加することができます。 3DGSは高負荷のため「環境編集」→「その他」で描画頻度と表示点数上限を調整できます。点数上限の変更は次回読み込みから適用されます。
    • 「モデルを追加」→「断層画像フォルダ」で非圧縮DICOMまたはヘッダーなしRAWを読み込みます。読み込み条件を指定して「分布を解析」を押すと、8bit変換前の値のヒストグラムを表示します。上下限をドラッグまたは数値指定し、XY・XZ・YZの3断面で矩形をドラッグして取り込み領域を選択できます。選択領域のヒストグラムを確認し、「読み込む」で元画像の選択領域から再サンプリングして8bitボリュームに変換します。Z方向の縮小に全スライスの平均・最大値・間引きを選べます。RAWの符号付き／符号なし、バイト順、積層順を確認し、必要に応じて濃淡を反転してください。ボリュームは伝達関数・自由断面・補助平面で観察できます。CT画質は標準・高画質・超高画質を選択でき、ISOでは法線平滑化と光沢を調整できます。WebGL2が必要です。圧縮DICOM・マルチフレームは未対応です。測定・診断用ではないため、それらの目的では使用しないでください。

    操作モード

    • 周回モード：モデルを中心にマウスで視点を回転・移動できます。
    • 飛行モード：キーボード (Q, W, E, R, A, S, D, F, 矢印キー) で自由に移動・視点変更ができます。Shiftキーで動きが速くなります。
    • いずれのモードでも、Ctrl+マウスクリックした場所を視点の中心にすることができます。

    環境編集

    • 背景色、背景画像、光源、出力解像度などの編集ができます。
    • 背景画像はエクイレクタングラー形式の画像をご用意ください。星空のエクイレクタングラー画像を用意すれば、簡易的なデジタルプラネタリウムとしても利用できます。
    • 解像度の数値は、6方向カメラの中央90°相当の領域に対するCubeCamera相当値です。1024はドームマスター換算で概ね2Kです。視野角を90°より広げた場合、内部の各面の描画解像度はそれに応じて増加します。

    モデル編集

    • 表示中の3Dモデルを選択し、座標位置や回転、サイズ、色などを個々に調整できます。
    • 選択したモデルは削除ボタンで削除できます。
    • SVG/JPEG/PNGは縦横比を保った平面テクスチャとして読み込みます。SVGとPNGの透過部分は保持します。SVGの独自フォントや外部参照画像は環境によって表示されない場合があります。
    • 頂点カラー付きOBJ・GLB/glTFの色を変更するには、「表示」タブで「オリジナルの色を使う」をオフにし、「モデルの色」を指定します。再びオンにすると元の色が復元されます。GLB/glTFでは画像の透過情報と材質の光沢などは保持されます。
    • CTの「表示」タブでは、読み込み済み8ビット密度分布のヒストグラムを見ながら、下限・上限を指定できます。境界線は直接ドラッグ可能です。ISOでは上限1.00で従来の下限等値面を表示し、上限を下げると上下限の密度境界面を表示します。Hybridでは密度範囲は内部DVRに適用され、表面の密度は独立指定です。「標準（青→黄）」の色の位置は選択した密度範囲内の割合で設定でき、上下限を変えても相対位置を維持します。
    • 「表示」タブでは、コマンダでアニメーションできる設定（モデル色・透明度）と、非対応の表示設定を分けています。copyボタンはコマンダ対応項目をコピーします。元の配色を使っている場合は透明度だけをコピーします。CTの描画方式・伝達関数・密度範囲・断面設定などは現時点ではコマンダで操作できません。見え方を先に調整し、透明度や座標・回転で演出してください。

    ドームビュー

    • 子ウィンドウでドームマスター形式のほか、6方向画像の展開表示、全球および上半球のエクイレクタングラー、透視投影、ドーム空間プレビューを表示できます。上半球エクイレクタングラーは水平360°・高度0～90°を展開し、4:1固定または画面のアスペクト比に合わせた出力を選べます。プラネタリウムへ投影する場合は、対応する射影方式を選び、外部映像入力に全画面表示してください。

    チルトコントロール（コントロール画面左下）

    • ドームビューの視点を上下左右に傾けることができます。初期状態では、コントロール画面の正面がドームビューの天頂です。
    • 実際に映し出すドームのスイートスポットに合わせてチルトを調整してください。

    カメラ座標・姿勢

    • コントロール画面左上にカメラの座標（pos）と姿勢（rot）が表示されます。値をコピーしてクリップボードに保存すると、コマンド入力にそのまま使うことができます。

    コマンダ

    • 事前に設定したコマンド（キュー）をもとに、アニメーションとして再生します。コマンドは1行ごとに解釈され、「//」「#」で始まる行はコメントとして扱われ、空行は無視されます。
    • 再生ボタン：キューを実行します。実行中はモデルの操作はできません。
    • 一時停止ボタン：一時停止すると画面が止まり、再開するかそのまま停止するかを選ぶ画面が表示されます。
    • 停止ボタン：再生途中でキューを停止します。
    • コマンド
      • カメラ座標：「pos: 0.00, 0.00, 0.00」の表記で記述します。「;」で区切ってカメラ姿勢とセットで記述できます。
      • カメラ姿勢：「rot: 0.00, 0.00, 0.00」の表記で記述します（単位は角度）。「;」で区切ってカメラ座標とセットで記述できます。
      • アニメーション時間：「dur: 0.00」または「duration: 0.00」の表記で記述します（単位は秒）。
      • イージング：アニメーション時間と併用し、アニメーションの速度を滑らかに変化させます。「cubic-bezier: 0.00,0.00,0.00,0.00」の形式。基本的に0～1の値を使いますが、負の値や1より大きな値を入れることもできます。また、定義値として「linear」「ease」「ease-in」「ease-out」「ease-in-out」を単独で表記することもできます。定義値を含む例を以下に示します。
        • 「linear」または「cubic-bezier: 0,0,1,1」：直線的に動き、無定義の場合と同じ。
        • 「ease」または「cubic-bezier: 0.25,0.1,0.25,1」：最初ゆっくり、最後はよりゆっくり動きます。
        • 「ease-in」または「cubic-bezier: 0.42,0,1,1」：最初はゆっくり、最後に向かって速く動きます。
        • 「ease-out」または「cubic-bezier: 0,0,0.58,1」：最初は速く、最後に向かってゆっくり動きます。
        • 「ease-in-out」または「cubic-bezier: 0.42,0,0.58,1」：最初と最後が同程度ゆっくり動きます。
        • 「cubic-bezier: 0,1,1,-1」：中盤で一旦戻る。
        • 「cubic-bezier: 0.5,0,0.5,1.5」：行き過ぎてから戻る。
      • ポーズ：「pause:0.00」の表記で記述します（単位は秒）。時間を表記しない場合は一時停止します。
      • チルト：「tilt: 0.00, 0.00」の表記で記述します（単位はいずれも度）。それぞれ上下チルト、左右チルトを表します。「;」で区切ってカメラ座標・姿勢、アニメーション時間、イージングと1行にまとめられます。例: `pos: 0, 0, 50; rot: 0, 0, 0; tilt: 30, 45; dur: 2; ease-in-out;`

    What is this?

    This is a 3D model viewer designed to project 3D models in planetariums or dome theaters. By selecting dome master projection in the child-window Dome View and displaying it full screen as an external video input to your planetarium, you can project images across the dome screen.

    This viewer was created with the goal of allowing anyone to easily run it directly in a browser, without requiring complex configurations or relying on restricted environments. Although it has limitations inherent to the browser environment, it includes a rich set of features necessary for 3D model presentations, such as model editing and animation tools. If you require more advanced capabilities or more stable performance, please consider using digital systems integrated into planetariums or Amateras Model Viewer.

    How to Use

    A more detailed guide has been compiled in a Notion article.

    We recommend enabling hardware (GPU) acceleration in your browser to ensure high-speed rendering. Performance may degrade or stutter on lower-spec devices, when increasing the resolution, or when loading large files.

    Adding Models

    • Click "Add Model" > "3D Model / Image" to load STL, OBJ, SVG, JPEG/PNG, GLB, glTF, or 3D Gaussian Splatting files (.splat or .ply). OBJ files with multiple objects are supported, but external MTL and texture files referenced by OBJ files are not loaded. GLB/glTF files must be self-contained; Draco, Meshopt, and BasisU compression extensions are not supported. For 3DGS, PLY support is limited to the GraphDECO format; compressed formats such as .ksplat and .spz are not supported. Adjust the frame limit and maximum point count under Environment > Others; the point limit applies to new imports. Files are selected one at a time, but additional models can be loaded later.
    • Use "Add Model" > "Tomographic Image Folder" to import uncompressed DICOM series or headerless RAW slices. After specifying import settings, click "Analyze Histogram" to inspect the pre-8-bit intensity distribution, adjust the limits by dragging or entering values, and select the import region in the XY, XZ and YZ orthogonal slice previews before loading. The Z reduction may use all slices (mean or max) or nearest-slice subsampling. For RAW, verify signedness, endianness, slice ordering, and use density inversion if needed. The resulting 8-bit display volume supports transfer functions, free clipping, and a helper plane. CT sampling quality can be set to Standard, High, or Ultra; ISO normal smoothing and specular highlights are adjustable. WebGL2 is required. Compressed and multiframe DICOM are not supported. This viewer is not intended for measurement or diagnosis and should not be used for those purposes.

    Control Modes

    • Orbit Mode: Allows you to rotate and pan the camera viewpoint around the model using the mouse.
    • Fly Mode: Allows you to freely move and change viewpoints using the keyboard (Q, W, E, R, A, S, D, F, and Arrow keys). Holding the Shift key increases movement speed.
    • In either mode, you can center the viewpoint on a specific location by holding Ctrl and clicking.

    Environment Editing (Env Edit)

    • You can edit settings such as background color, background images, lighting, and output resolution.
    • Please provide background images in the equirectangular format. By using an equirectangular image of the starry sky, it can function as a simple digital planetarium.
    • The resolution setting represents the CubeCamera-equivalent resolution across the central 90-degree region of each of the six camera views. A setting of 1024 corresponds to roughly a 2K dome master. Wider face fields of view use larger internal render targets.

    Model Editing (Model Edit)

    • Select a 3D model currently on display to individually adjust its position coordinates, rotation, size, color, etc.
    • The selected model can be removed using the delete button.
    • SVG, JPEG and PNG are displayed as flat, textured panels with the image aspect ratio preserved. SVG retains text, colors and transparency; PNG transparency is retained as well. Custom SVG fonts and externally linked images may not display in all environments.
    • To override vertex colors in OBJ or GLB/glTF models, uncheck "Use Original Color" in Display and choose "Model Color". Recheck it to restore the source colors. GLB/glTF transparency and material shading are preserved.
    • In the CT Display tab, the histogram shows the imported 8-bit density distribution and lets you set minimum and maximum density values or drag the boundaries. For ISO, a maximum of 1.00 preserves the original minimum isosurface; reducing the maximum displays the first encountered boundary of the selected density band. For Hybrid, the range applies to interior DVR while the surface level is independent. In the standard blue-to-yellow palette, color endpoints are positioned relative to the selected density range and retain their percentages when its limits change.
    • In the Display tab, Commander-animatable settings (model color and opacity) are separated from settings that cannot be scripted. The Copy button includes color and opacity, or only opacity while original colors are active. CT rendering styles, transfer functions, density limits and clipping are not currently supported in Commander; configure the appearance first, then animate opacity or model transforms.

    Dome View

    • Opens a child window supporting dome master projections, cube-net layouts, full-sphere and upper-hemisphere equirectangular, perspective views, and a 3D dome-space preview. Upper-hemisphere equirectangular maps 360° of longitude and elevations from the horizon to zenith, with either a fixed 4:1 image or output fitted to the screen aspect ratio. For planetarium projection, select an appropriate projection and display it full screen through the external video input.

    Tilt Controls (Bottom Left of Control Screen)

    • Allows you to tilt the Dome View's camera angle up, down, left, and right. By default, the front direction of the control screen corresponds to the zenith (top center) of the Dome View.
    • Adjust the tilt according to the sweet spot of the actual dome you are projecting on.

    Camera Coordinates & Attitude

    • The camera's coordinates (pos) and orientation/attitude (rot) are displayed in the upper-left corner of the control screen. You can copy these values to your clipboard and use them directly in the commander input.

    Terminal

    • Plays back animations based on pre-configured commands (cues). Commands are interpreted line by line. Lines starting with "//" or "#" are treated as comments, and empty lines are ignored.
    • Play Button: Executes the cues. Model controls are disabled during playback.
    • Pause Button: Pauses playback, stopping the screen and displaying a prompt to either resume or stop.
    • Stop Button: Halts cue playback mid-way.
    • Commands
      • Camera Coordinates: Described in the format "pos: 0.00, 0.00, 0.00". Can be written together with camera attitude by separating them with a semicolon ";".
      • Camera Attitude: Described in the format "rot: 0.00, 0.00, 0.00" (unit: degrees). Can be written together with camera coordinates by separating them with a semicolon ";".
      • Animation Duration: Described in the format "dur: 0.00" or "duration: 0.00" (unit: seconds).
      • Easing: Used in conjunction with animation duration to smoothly change the animation speed. Written in the form "cubic-bezier: 0.00,0.00,0.00,0.00". Generally, values between 0 and 1 are used, but negative values or values greater than 1 can also be entered. You can also use predefined keywords on their own, such as "linear", "ease", "ease-in", "ease-out", or "ease-in-out". Examples including predefined values are shown below:
        • "linear" or "cubic-bezier: 0,0,1,1": Moves linearly, identical to having no easing defined.
        • "ease" or "cubic-bezier: 0.25,0.1,0.25,1": Starts slowly, and ends even more slowly.
        • "ease-in" or "cubic-bezier: 0.42,0,1,1": Starts slowly, then accelerates toward the end.
        • "ease-out" or "cubic-bezier: 0,0,0.58,1": Starts quickly, then decelerates toward the end.
        • "ease-in-out" or "cubic-bezier: 0.42,0,0.58,1": Starts and ends slowly at a similar pace.
        • "cubic-bezier: 0,1,1,-1": Briefly moves backward mid-way.
        • "cubic-bezier: 0.5,0,0.5,1.5": Overshoots the target before returning.
      • Pause: Described in the format "pause:0.00" (unit: seconds). If no time is specified, it triggers an interactive pause.
      • Tilt: Described in the format "tilt: 0.00, 0.00" (both units are in degrees), representing vertical tilt and horizontal tilt respectively. Can be combined with camera coordinates, attitude, duration and easing on the same line, separated by semicolons ";". Example: pos: 0, 0, 50; rot: 0, 0, 0; tilt: 30, 45; dur: 2; ease-in-out;
